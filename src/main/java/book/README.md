# 자바의 정석 따라 치기

| 폴더 | 범위 |
|---|---|
| `io/` | I/O 장 — `DataInputStream` / `DataOutputStream` (`readInt`, `readFully`, `writeInt`) |
| `tcp/` | 네트워킹 장 — TCP 소켓 프로그래밍 (`ServerSocket`, `Socket`, 스레드로 여러 클라이언트 받기) |

`URL`, `URLConnection`, UDP 부분은 펌뱅킹과 관계없어서 건너뛴다.

예제를 그대로 치기보다, 친 뒤에 한 줄씩 바꿔 보며 무엇이 달라지는지 주석으로 남긴다.
