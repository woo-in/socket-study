# 2. 경계 문제 재현

## 목표

TCP에는 메시지 경계가 없다는 것을 직접 본다.

## 할 것

- 클라이언트를 Java로 만든다. `"HELLO"`와 `"WORLD"`를 `write` 두 번으로 연달아 보낸다.
- 서버는 `byte[1024]`로 `read`를 반복하며, 한 번에 몇 바이트를 읽었는지 출력한다.
- 서버의 버퍼를 `byte[3]`으로 줄여서 다시 해 본다.

## 확인할 것

- `write` 2번이 `read` 1번에 붙어서 오는 경우 (`HELLOWORLD`)
- 버퍼가 작으면 한 메시지가 여러 번에 잘려서 오는 경우
- 그렇다면 서버는 "어디까지가 메시지 하나"인지 어떻게 알 수 있는가?

- [ ] 잘려서 오는 경우를 출력으로 확인했다
