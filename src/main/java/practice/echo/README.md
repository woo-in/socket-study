# 1. 에코 서버

## 목표

`ServerSocket`으로 받은 바이트를 그대로 돌려주는 서버를 만든다.

## 할 것

- 포트 9000에서 연결을 하나 받고, 읽은 것을 그대로 쓴다.
- 터미널에서 `nc localhost 9000`으로 붙어 글자를 쳐 본다.
- 서버에서 `read`가 돌려준 바이트 수와 내용을 출력한다.

## 확인할 것

- HTTP처럼 요청 줄·헤더가 없다. 친 바이트만 오간다.
- `nc`를 `Ctrl+C`로 끊으면 서버의 `read`가 무엇을 돌려주는가?

## 완료 조건

- [ ] `nc`로 친 글자가 그대로 돌아온다
- [ ] 상대가 끊었을 때 서버가 예외 없이 연결을 닫는다
