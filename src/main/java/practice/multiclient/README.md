# 6. 여러 클라이언트 동시 처리

## 목표

연결 하나당 스레드 하나로 여러 클라이언트를 동시에 받는다. firmbanking-mock 전문 서버의 뼈대다.

## 할 것

- 3번(길이 헤더) 서버를 바탕으로, `accept`한 소켓을 `ExecutorService`(고정 크기 스레드 풀)에 넘긴다.
- 클라이언트 5개를 동시에 띄워 각각 메시지를 보낸다. 서버는 스레드 이름과 함께 출력한다.
- 스레드 풀 크기를 2로 줄이고 다시 해 본다.

## 확인할 것

- 스레드 풀 없이(`accept` 후 바로 처리) 하면 두 번째 클라이언트는 어떻게 되는가?
- 풀 크기보다 클라이언트가 많으면 나머지는 어디서 기다리는가?
- 서버를 끌 때 열려 있는 연결과 스레드는 어떻게 정리해야 하는가?

## 완료 조건

- [ ] 클라이언트 5개의 메시지를 동시에 처리한다
- [ ] 풀 크기를 줄였을 때의 동작을 설명할 수 있다
